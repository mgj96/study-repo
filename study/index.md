## 이 사이트는?

GitHub 저장소 [`mgj96/study-repo`](https://github.com/mgj96/study-repo)의 학습 노트를 **한 권의 책**으로 묶은 사이트입니다.

- 📖 왼쪽 메뉴가 곧 목차입니다. 페이지 아래 **이전/다음**만 따라가면 서문부터 17장까지 이어집니다.
- 🎧 각 페이지 위의 **원문 링크 복사** 버튼으로 Gemini·NotebookLM에 바로 넣을 수 있습니다. 부 단위 합본 링크는 [서문](https://mgj96.github.io/study-repo/book/preface/00-how-to-read)에 있습니다.
- 🔎 상단 **검색(Ctrl/⌘+K)** · **다크모드** 지원.
